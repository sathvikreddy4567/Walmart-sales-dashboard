# Walmart-sales-dashboard
Walmart Sales Analysis Dashboard
Project Overview

This project analyzes Walmart sales data to uncover key business insights related to revenue, customer behavior, product performance, and sales trends. Using data analytics and visualization techniques, the dashboard helps stakeholders make data-driven decisions by identifying high-performing categories, sales patterns, and business opportunities.

Objectives
Analyze overall sales performance across different regions and categories.
Identify top-performing products and departments.
Track revenue, profit, and sales trends over time.
Understand customer purchasing behavior.
Evaluate key business KPIs to support strategic decision-making.
Tools & Technologies
SQL – Data cleaning, transformation, and analysis
Power BI – Interactive dashboard creation and visualization
Excel – Data preprocessing and validation
DAX – KPI calculations and advanced measures
Key Insights
Monitored total sales, profit, and order volume.
Identified top-selling products and categories.
Analyzed monthly and yearly sales trends.
Compared performance across different locations and customer segments.
Evaluated business performance using interactive filters and KPIs.
Dashboard Features
Executive Summary Dashboard
Sales Trend Analysis
Product Performance Analysis
Customer Insights
Regional Performance Tracking
Interactive Slicers and Filters
Business Value

This dashboard enables business users to:

Make informed decisions using real-time insights.
Optimize inventory and product strategies.
Improve sales performance monitoring.
Identify growth opportunities across regions and categories.
